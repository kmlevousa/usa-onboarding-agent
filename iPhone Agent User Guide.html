1. App kya hai — ek nazar mein

iPhone Agent aap ka haath wala ops assistant hai. Do kaam ek saath karta hai:

  • USA onboarding: clients ke liye bank/merchant research, sign-up prefill plan, KYC handover aur website checklist
  • Personal assistant: EIN, KYC, high-risk, bank shortlist jaisay sawalon ke jawab — online bhi, offline bhi

2. Pehli dafa kya set karein

  1. Settings tab kholein (neeche right corner)
  2. WhatsApp number likhein — country code ke saath, jaise +92 300 1234567 → Number save karein button dabayein
  3. (Optional) Live AI ke liye API base URL + API key + model likhein → Save → Test connection se check karein. Key ke baghair bhi app poora chalta hai — local brain mode mein
  4. (Optional) Notifications chip ko ON karein — lekin yad rakhein: yeh sirf installed PWA par kaam karta hai (Section 10.2 dekhein)
API key kya hai aur kahan se aati hai?Live AI ke liye kisi OpenAI-compatible service ka key chahiye (jaise OpenAI sk-…, ya Zhipu/Z.ai GLM). Key sirf aapke device par rehti hai aur sirf aapke endpoint par jaati hai. Na mili ho to chain ki baat — local brain onboarding ke saare kaam offline kar deta hai.

4. Client par kaam — 6-step Workflow

Har client ka apna workflow stepper hai. App khud batata hai agla step kaunsa hai — jo step abhi karna hai us par NEXT chip hoti hai, mukammal steps par DONE. Step ke andar "Chalayein" button dabate hi step mukammal ho jaata hai.

2Risk classificationIndustry keywords se low/medium/high riskRisk level + expectations (high-risk par warning)
3Bank & processor researchCurated shortlist: 4 banks + 4 processors, har ek par note aur VERIFY linkCandidate list — har link official page kholta hai; apply se pehle signer-eligibility check karein

6Website approval checklistMerchant review ke liye 5-item checklistCheckboxes — har item ka status save hota hai
Sab se important rule — KYC boundaryApp Sec 1–3 (business data entry) tak kaam karti hai. Sec 4 (ID upload, selfie/video verification), Sec 5 (certification/e-sign) aur final submit hamesha client khud karta hai. App aapko is kaam par koi shortcut nahi deti — aur na de, yehi iski gaurant hai. SSN/ITIN, ID photos, OTP codes kabhi bhi app mein na likhein.

9. FAQ — bar-bar pooche sawal

Naya client ka data add karne mein koi shortcut?

Home screen ke suggestion card se bhi seedha ja sakte hain. Data pack jitna mukammal hoga, workflow utna smooth — adhoore pack par validation hi ruk jaati hai (yeh jaan boojh kar hai).

Internet band ho jaye to kya hota hai?

Kuch nahi hota — clients, steps, chat sab local rehta hai. Risk check, prefill plan, handover note aur checklist sab offline chalti hain. Net wapas aate hi ribbon update ho jaata hai.

Data kabhi gayab ho sakta hai?

Browser ka data clear kiya jaye ya "Clear data" dabaya jaye to jaata hai. Is liye behtar hai hafta-war Data export kar ke JSON apne paas rakhna.

Kya main ek hi app par kai clients chala sakta hoon?

Haan — koi limit nahi. Har client ka apna workflow aur progress alag save rehta hai.

Client kisi aur shahar/country mein hai to?

Koi farq nahi — onboarding USA business ka hai, client duniya mein kahin bhi ho sakta hai. Bas signer ki residency field sahi bharein — banks ka filter isi par chalta hai.

Live AI ka jawab ghalat lagta hai to?

AI jawab "verify current official source" ki taakid ke saath deta hai. Bank/processor policies aksar badalti hain — koi bhi decision official page (VERIFY links) dekh kar lein.

10. Safe-use ki 3 pakki rules

Rule 1 — Sensitive data kabhi app mein nahiSSN, ITIN, passport/ID photos, selfies, bank passwords, OTP — yeh sirf client khud bank/processor ke official portal mein daalta hai. Na chat mein, na client form mein, na Settings mein.
Rule 2 — Attestation aur submit hamesha client kaApp data entry tak jaanti hai (Sec 1–3). "I certify", Terms of Service, e-sign, final Submit — yeh client ke apne kaam hain. App is liye Sec 4 par khud ruk jaati hai.
Rule 3 — Approval kabhi guarantee nahiKoi bhi bank/processor approval ya fees ki zuban na de. High-risk client ko pehle hi saaf bata dein: reserves, lambi underwriting, mehdud options mumkin hain.
