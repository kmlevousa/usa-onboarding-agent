Row 1 · Project intro
Yeh kya hai

iPhone Agent — ek haath wala ops cockpit

USA business onboarding + personal assistant ka combined mobile app. Client data packs, risk classification, sign-up prefill plan, KYC handover notes aur website checklist — sab offline chalte hain. Internet ho to live AI brain jaag uthta hai; na ho to local brain kaam karta rehta hai.

Kis ke liye

Solo operator · iPhone-first

Ek banda jo clients ke liye USA business setup karta hai. Chalti firti zindagi — beach mein network slow, KYC client ke zimmay. App ka poora workflow bina internet ke bhi poora chalta hai; network wapas aate hi live AI aur curated updates milte hain. UI ki zubaan Roman Urdu, terms English.

Kya solve karta hai

Teen dard, teen jawab

  • Data adhoora? Data pack validation pehle chalti hai — forms aadhe nahi bharay jaate.
  • KYC ka boundary? Handover note khud banta hai — WhatsApp par ek tap mein client ko chala jaata hai. Attestation hamesha client ka kaam.
  • Bhoolna? Har client ka stepper progress yaad rakhta hai — app kholte hi agla step samne.

Hybrid brain — data flow

Offline = poora logic local (validation, risk, prefill plan, handover, checklist). Online = wahi logic + live AI jawab (user ki apni API key se, sirf user ke endpoint par jaati hai) + curated research refresh reminder.

Local
localStorage · clients, steps, chat, settings — koi server nahi
Online
OpenAI-compatible endpoint (user key) · wa.me deep links · curated sources re-verify
Private
SSN/ITIN, ID photos, OTP — app kabhi maangta hi nahi; handover mein client ko portal bhejta hai

Differentiation — do yaadgaar cheezein

Mode ribbon — har screen ke upar chip: ONLINE · LIVE AI ya OFFLINE · LOCAL BRAIN. User ko hamesha pata rehta hai abhi kaunsa dimaag chal raha hai.

Handover ritual — KYC rukne par app ek tayyar note banati hai: resume point, client ke steps, documents — aur seedha WhatsApp bhejne ka button. Yehi is app ka signature moment hai.
